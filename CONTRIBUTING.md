# Contributing to AI-NIDS for Apertre 3.0

Welcome to the **AI-Network-Intrusion-Detection** project! We are thrilled to be part of the **Apertre 3.0** open-source journey. Whether you are a first-time contributor or an experienced developer, we value your input.

## 🌟 How to Contribute

We want to make contributing as easy as possible. Here’s a quick guide:

### 1. Find an Issue
- Check the [Issues](https://github.com/sr-857/AI-Network-Intrusion-Detection/issues) tab.
- Look for tags like `good first issue`, `documentation`, or `enhancement`.
- If you have a new idea, feel free to open a new issue to discuss it!

### 2. Fork & Clone
1. Fork this repository to your own GitHub account.
2. Clone it locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/AI-Network-Intrusion-Detection.git
   ```

### 3. Create a Branch
Always work on a new branch for your changes:
```bash
git checkout -b feature/my-amazing-feature
```

### 4. Make Changes
- **Code**: Follow the existing style (Python/Streamlit).
- **Docs**: improvements to README or inline comments are always welcome.

### 5. Test
Ensure the application runs locally:
```bash
streamlit run nids_main.py
```

### 6. Commit & Push
```bash
git add .
git commit -m "feat: Add amazing feature"
git push origin feature/my-amazing-feature
```

### 7. Open a Pull Request (PR)
- Go to the original repository.
- Click "New Pull Request".
- Describe your changes clearly.
- Mention that this is for **Apertre 3.0**.

## 🤝 Code of Conduct
Please be respectful and kind to other contributors. We are all here to learn and grow together.

Thank you for contributing! 🚀
